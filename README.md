# Popcart Remastered

A full-stack e-commerce platform engineered with TypeScript and GraphQL, featuring an optimized user interface and robust backend services.

## Overview

Popcart Remastered is a modern commerce application designed to provide a seamless shopping experience while offering a scalable backend infrastructure for inventory, orders, and product management. 

This project focuses on:
- High-performance frontend experiences and responsive design
- Type-safe development with TypeScript
- GraphQL-based data fetching and application architecture
- Reliable backend services for real-world commerce workflows

## Features

- **Product Browsing:** Seamless catalog management and intuitive shopping workflows.
- **Authentication:** Secure login flows utilizing Google OAuth.
- **Brand Profiles:** Dedicated views for brand and vendor profiles.
- **Order Processing:** Automated transaction confirmations via Nodemailer.
- **Robust API:** GraphQL-powered API interactions for efficient data delivery.

## Tech Stack

- **Language:** TypeScript, HTML/CSS
- **API:** GraphQL (Apollo Client & Apollo Server)
- **Authentication:** Google OAuth
- **Email Service:** Nodemailer
- **Deployment:** Render (Backend)
